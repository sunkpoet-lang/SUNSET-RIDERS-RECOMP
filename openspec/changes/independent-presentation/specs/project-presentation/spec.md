## ADDED Requirements

### Requirement: Independent presentation
The project's public introduction and window caption SHALL identify Sunset Riders research independently, retaining third-party authorship and licence obligations.

#### Scenario: Read the introduction or launch the window
- **WHEN** a user reads the README introduction or opens the native game window
- **THEN** the text identifies the Sunset Riders project without another product's branding
- **AND** original third-party copyright notices remain unchanged.
